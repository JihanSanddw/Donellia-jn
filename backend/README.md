Donellia
-- Dono + sentuhan nama Italia
Dono berarti hadiah dalam bahasa Italia. Donellia merupakan nama kreasi dengan bunyi lembut dan feminin.
Makna: Tempat untuk merencanakan hadiah bagi diri sendiri maupun orang-orang yang kamu sayangi.
Tagline: “Un Pensiero, Un Sorriso.”
--Artinya: Sebuah perhatian, sebuah senyuman.
